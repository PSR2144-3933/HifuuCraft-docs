# 主页 {#home}

欢迎来到粘液科技！
粘液科技提供了远远超过 400 种物品和方块，其中包括：

* 背包
* 核反应堆
* 魔法祭坛、符文和法杖
* 物品传输系统
* 电力网络
* 电力机器
* 可编程式机器人 (挖矿机器人)
* 全息文字投影仪
* 爆炸镐
* 还有很多很多很多……
